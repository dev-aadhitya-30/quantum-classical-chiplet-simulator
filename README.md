# Quantum-Classical Chiplet Hybrid Computing Simulator

## Overview

The Quantum-Classical Chiplet Hybrid Computing Simulator is a research-oriented simulation framework designed to evaluate the integration of Quantum Processing Units (QPUs) and Classical Processing Units (CPUs) within a chiplet-based computing architecture.

The project investigates how hybrid chiplet architectures can improve communication efficiency, reduce latency, enhance thermal isolation, and support faster quantum error-correction feedback compared to conventional quantum computing systems.

---

## Problem Statement

Current quantum computing systems often rely on external classical processors for control and error-correction tasks. This separation introduces communication delays, scalability challenges, and performance bottlenecks.

This project explores a hybrid chiplet-based architecture where quantum and classical components are integrated within a unified package to improve system efficiency and computational performance.

---

## Objectives

- Model a Quantum-Classical Chiplet Hybrid Architecture.
- Analyze instruction round-trip latency.
- Evaluate thermal isolation between CPU and QPU regions.
- Study signal integrity and electromagnetic interference (EMI).
- Simulate quantum error-correction feedback mechanisms.
- Compare architectural performance and scalability characteristics.

---

## Key Features

### Architecture Modeling
Simulates the interaction between quantum and classical chiplets within a shared computing environment.

### Latency Analysis
Evaluates communication delays and instruction processing performance across different architectural configurations.

### Thermal Evaluation
Analyzes heat distribution and thermal isolation requirements for stable quantum operation.

### Signal Integrity Assessment
Studies the impact of noise and electromagnetic interference on system performance.

### Scalability Analysis
Examines how the architecture behaves under increasing workloads and larger system configurations.

### Quantum Error-Correction Feedback Simulation
Models feedback loops required for efficient quantum error detection and correction.

## Results

The simulator demonstrates the potential advantages of integrating quantum and classical chiplets within a unified architecture.

Key findings include:

- Reduced communication latency between quantum and classical components.
- Improved thermal management through architectural separation.
- Enhanced support for low-latency quantum error-correction feedback.
- Better scalability compared to traditional externally connected architectures.
- Insights into signal integrity and electromagnetic interference considerations.
